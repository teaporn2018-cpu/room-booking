แอปมือถือ ระบบจองห้องพัก (PWA) — วิธีติดตั้ง
=====================================================

ขั้นที่ 1  อัปเดตโค้ด Apps Script (ทำครั้งเดียว)
- วาง Code.gs และ Index.html เวอร์ชัน 1.6 แทนของเดิม แล้วกดบันทึก
- ทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้ > แก้ไข > เวอร์ชันใหม่ > ทำให้ใช้งานได้
- "ผู้มีสิทธิ์เข้าถึง" ต้องเป็น "ทุกคน" (ถ้าเป็น "ทุกคนที่มีบัญชี Google" แอปมือถือจะเปิดไม่ขึ้น)

ขั้นที่ 2  ใส่ลิงก์เว็บแอป (ไม่บังคับ แต่แนะนำ)
- เปิดไฟล์ config.js ด้วย Notepad
- วางลิงก์ไว้ในเครื่องหมาย ''  เช่น  window.APP_URL = 'https://script.google.com/macros/s/xxxx/exec';
- ถ้าไม่ใส่ แอปจะถามลิงก์ตอนเปิดครั้งแรกในแต่ละเครื่อง

ขั้นที่ 3  นำไฟล์ขึ้นเว็บฟรีด้วย GitHub Pages (ทำบนคอมพิวเตอร์)
1) สมัคร/เข้าสู่ระบบที่ https://github.com
2) กด + มุมขวาบน > New repository
   - Repository name: room-booking   (ภาษาอังกฤษ)
   - เลือก Public  แล้วกด Create repository
3) กดลิงก์ "uploading an existing file"
   ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (ทุกไฟล์ รวมรูป .png ทั้ง 5 ไฟล์)
   ไปวาง แล้วกด Commit changes
4) ไปที่ Settings > Pages
   - Source: Deploy from a branch
   - Branch: main  /(root)  แล้วกด Save
5) รอ 1–2 นาที จะได้ลิงก์แอป เช่น  https://ชื่อผู้ใช้.github.io/room-booking/

ขั้นที่ 4  ติดตั้งบนมือถือ
Android (Chrome)
- เปิดลิงก์แอปจากขั้นที่ 3 > แตะปุ่มสีทอง "ติดตั้งแอป"
  (หรือเมนู ⋮ > ติดตั้งแอป / เพิ่มลงในหน้าจอหลัก)
iPhone / iPad (ต้องใช้ Safari)
- เปิดลิงก์แอป > แตะปุ่มแชร์ ⬆️ > "เพิ่มไปยังหน้าจอโฮม" > เพิ่ม

จะได้ไอคอนแมนชั่นบนหน้าจอ เปิดแบบเต็มจอเหมือนแอปทั่วไป
ส่งลิงก์จากขั้นที่ 3 ให้พนักงานติดตั้งแบบเดียวกันได้ (แต่ละคนเข้าระบบด้วยชื่อผู้ใช้ของตัวเอง)

หมายเหตุ
- ข้อมูลทั้งหมดยังอยู่ใน Google Sheets ต้องต่ออินเทอร์เน็ตเสมอ
- แก้ Code.gs ภายหลัง: แค่ทำให้ใช้งานได้เป็นเวอร์ชันใหม่ ไม่ต้องอัปโหลดไฟล์แอปใหม่
- เปลี่ยนลิงก์เว็บแอปในเครื่องใดเครื่องหนึ่ง: เปิดลิงก์แอปแล้วเติม ?setup ต่อท้าย
